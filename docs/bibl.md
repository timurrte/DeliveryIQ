## Як вставляти у Word

1. Відкрити v2_диплом.docx.
2. Для кожного рядка таблиці: знайти цитований фрагмент через Ctrl+F → дописати `[N]` після крапки чи після відповідного слова.
3. У кінці роботи створити новий розділ «**ПЕРЕЛІК ДЖЕРЕЛ ПОСИЛАНЬ**» (стиль Heading 1, як у решти структурних елементів).
4. Скопіювати готовий блок з цього файлу як просту нумеровану ASCII-розмітку (без таблиць).
5. Якщо у роботі вже є якесь існуюче оформлення посилань [1]-[6] — підставити їх повний бібліографічний опис на ту ж позицію.
